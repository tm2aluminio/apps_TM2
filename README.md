# apps_TM2
Repositório do aplicativos da TM2
### Aplicativos

- **Relatório de Obras TM2**: elabora, aprova e arquiva relatórios de visita de obra, com fotos, itens de ação e fluxo de aprovação. [Abrir app](https://tm2aluminio.github.io/apps_TM2/RelatorioObras_TM2.html)
- **ImportSisGO**: importa os dados das planilhas de orçamento para a aba COMERCIAL do SisGO. [Abrir app](https://tm2aluminio.github.io/apps_TM2/ImportSisGO.html)
- **GCap TM2**: gestão de capacidade de produção, a partir dos arquivos do SisGO de cada obra. [Abrir app](https://tm2aluminio.github.io/apps_TM2/GCap_TM2.html)
- **SisGO TM2 (dashboard)**: acompanhamento de obras do SisGO. [Abrir app](https://tm2aluminio.github.io/apps_TM2/SisGO-TM2%20%284%29.html)

### Manuais e documentos

- **Manual de uso do Relatório de Obras TM2**: guia ilustrado, para ler no celular. [Abrir manual](https://tm2aluminio.github.io/apps_TM2/Manual_RelatorioObras_TM2.html)
- **Manual SisGO TM2**: manual do SisGO em formato A5, para leitura. [Abrir PDF](https://tm2aluminio.github.io/apps_TM2/Manual_SisGO_TM2_A5_leitura.pdf)
- **Fluxo SisGO TM2**: fluxo do processo no SisGO. [Abrir PDF](https://tm2aluminio.github.io/apps_TM2/Fluxo%20SisGO%20TM2.pdf)

### Planilha

- **SisGO (ver44)**: modelo do SisGO em Excel. [Baixar planilha](https://tm2aluminio.github.io/apps_TM2/SisGO%20%28ver44%29.xltm)
